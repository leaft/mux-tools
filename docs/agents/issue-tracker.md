# Issue and specification sources

This project uses GitHub Issues in `leaft/mux-tools` when an issue number is supplied. Read one with `gh issue view NUMBER --repo leaft/mux-tools`.

The initial implementation comes from the owner's conversation and is recorded in `docs/spec.md`; no originating issue number exists. For the initial release, that file is the Spec review source. Standards are in `CONTRIBUTING.md`.
