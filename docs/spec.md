# wt-switch 需求与验收

来源：本项目发起人的对话要求，确认日期 2026-11-23。

## 已确认范围

- 项目名为 `mux-tools`，可继续加入面向 Agent 终端复用器的快捷脚本。
- 本次命令 `wt-switch` 使用 Bash + fzf + jq；支持 macOS 自带 Bash 3.2。
- 在当前仓库中列出已存在的 Git worktree，支持搜索、选择和取消。
- 每个 worktree 在当前 Rex session 或 Herdr desktop space 中对应一个标签页；已有则聚焦，没有则创建，启动目录是 worktree 根目录。
- 路径是关联依据；标签页改名后仍能复用。能发现当前目录位于该 worktree（含子目录）的现有终端标签页。
- 已关闭的标签页记录失效后可重新创建；并发选择同一 worktree 不产生重复标签页。
- 保持其他会话、标签页、前台程序以及 Git 工作区内容；不创建、删除 worktree 或切换 Git 分支。
- 公开发布到 GitHub，提供安装、快捷键接入、验证方法和已知限制。

## 实现约定

- `--path` 为可测试、可自动化的直接选择入口，仅接受属于当前仓库的现有 worktree 根目录。
- `--list` 只输出 JSON，便于预览且不连接宿主；`--scope` 可明确指定 session/space。
- 当前 Herdr 是 `herdr-app` + `hc` 的桌面产品，不是 `herdr` TUI。后者不在本版支持范围。
- 本版只处理本机目录与本机 Herdr space；不支持远程文件系统、Windows 原生 Shell。
- 控制字符路径不进入单行选择器；空格、中文、引号、反斜杠、美元符号和反引号按普通参数处理。
- 缓存按宿主实例与 session/space 隔离。无效状态报告错误，不静默丢弃；聚焦失败时不创建替代标签页。
- 快捷键仅交付配置示例，由用户选择启用；不覆盖现有应用配置。

## 验证边界

自动化测试使用真实临时 Git 仓库、真实 jq/fzf、与已核对 CLI 响应形状一致的宿主替身。替身测试不能证明真实 App 兼容性；另用临时 Rex session 和 Herdr space 做实际创建、复用、关闭后重建检查，并清理测试资源。
